# Portfolio

Personal portfolio site. Static HTML/CSS/JS.

## Structure
- `index.html` — home, project grid loaded from `data/projects.json`
- `project.html` — case study page (`?p=slug`)
- `about.html` — bio + CV
- `data/projects.json` — all project data

## Local dev
Use VS Code Live Server (right-click index.html → Open with Live Server).

## Deploy
GitHub Pages → Settings → Pages → Deploy from `main` / root.
